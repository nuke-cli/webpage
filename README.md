# nuke-cli webpage

> nuke-cli webpage.

- Use **npm run** or **yarn** to run any of the scripts bellow.

### Run project through Docker container:

- **Requires Docker (and docker-componse).**

- Runs ```app:up``` to build and start the container (port 4000).

- Runs ```app:down``` to take the container down.


### Run project locally:

- Install the packages through ```npm install``` or ```yarn install```

- Runs ```app:dev``` to start the project into a local server.


### Linting:

- **Linting runs automatically when commiting.**

- Runs ```lint``` script if you do wanna lint your code manually.
